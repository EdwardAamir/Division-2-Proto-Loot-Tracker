# Screenshots

This directory contains app screenshots for the README and documentation.

## Needed Screenshots

Please add the following screenshots to showcase the app:

1. **main_screen.png** - Main app screen showing the five escalation targets
2. **countdown.png** - Countdown timer to next reset
3. **notification.png** - Example of the daily notification
4. **chinese_ui.png** - App interface in Simplified Chinese
5. **dark_mode.png** (optional) - If dark mode is supported

## Guidelines

- Use actual device screenshots (not emulator if possible)
- Resolution: At least 1080p
- Show realistic data from prototrack.gg
- Include device frame for a polished look (optional)
- Keep file sizes reasonable (compress if needed)

Once added, reference them in the main README.md with:
```markdown
## Screenshots

<div align="center">
  <img src="screenshots/main_screen.png" width="250" alt="Main Screen">
  <img src="screenshots/countdown.png" width="250" alt="Countdown">
  <img src="screenshots/chinese_ui.png" width="250" alt="Chinese UI">
</div>
```
